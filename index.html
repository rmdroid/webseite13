01 · Schnellcheck

Gehören Sie zu den 13 %?

Fünf Fragen, zwei Minuten. Das Ergebnis ist eine erste Einordnung mit klarer Empfehlung: investieren, prototypisieren, absichern oder stoppen.

So lesen Sie das Ergebnis

Die Punkte bilden ab, wie belastbar Use Case, Datenlage, Risiko und Verantwortung heute sind.

  • Investieren. Die Grundlagen tragen. Der Check verdichtet sie zur Entscheidung.
  • Prototyp. Die Idee ist konkret. Jetzt zeigt ein Workflow, ob sie im Alltag funktioniert.
  • Absichern. Compliance und Verantwortung sind offen. Erst klären, dann bauen.
  • Stoppen. Zu viele Voraussetzungen fehlen. Ein schneller Start erhöht das Risiko.

03 · Arbeitsprinzip

Code statt PowerPoints.

Beratung endet nicht auf einer Folie. Sie muss als Workflow, Entscheidungslogik oder Governance-Regel im Betrieb ankommen. Sonst war sie Unterhaltung.

  • 01Keine KI ohne Prozess.

    Wenn niemand sagen kann, welche Arbeit sich konkret ändert, gibt es nichts zu automatisieren.

  • 02Keine Demo ohne Betriebspfad.

    Wer wartet das System, wer eskaliert bei Fehlern, was kostet der Betrieb im dritten Jahr?

  • 03Keine Automatisierung ohne Kontrollpunkt.

    Jeder Workflow bekommt Stellen, an denen ein Mensch prüft, stoppt oder freigibt.

  • 04Keine Schulung ohne Transfer.

    Nach dem Termin muss jemand etwas anders tun. Messbar, an der eigenen Aufgabe.

  • 05Keine Strategie ohne Entscheidung.

    Ein Strategiedokument, das keine Entscheidung erzwingt, ist Feierabendliteratur.

05 · EU AI Act

Welche Risikoklasse hätte Ihr Vorhaben?

Drei Fragen, eine erste Einordnung nach den vier Klassen der KI-Verordnung. Keine Rechtsberatung, aber genug, um zu wissen, worüber Sie sprechen.

1. Wofür soll das System eingesetzt werden?
2. Welche Wirkung hat es auf Personen?
3. Wie viel menschliche Kontrolle ist vorgesehen?
Noch keine Einordnung

Beantworten Sie die drei Fragen.

Die Einordnung erscheint hier, sobald alle drei Angaben vorliegen. Sie ändert sich sofort, wenn Sie eine Antwort wechseln.
